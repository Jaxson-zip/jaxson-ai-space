## 知识录入的后续定位

量化停止后，服务器上同版本 CMS 只读预演明确返回 `CMS_TIMEOUT_IMPORTING`，没有执行 apply。诊断另确认运行容器和当前 production.env 只有已有管理员邮箱，没有 CMS 登录密码；运维目录中也没有对应凭据配置。此前工具没有在初始化前检查这一必要条件，已新增先失败后通过的缺凭据快速拒绝，并保留外层超时中的安全阶段标记。

站长表示希望直接输入密码，已提供本机隐藏输入框；密码由当前 Windows 用户 DPAPI 加密并受本机私有运维目录 ACL 保护，不进入聊天、Git、命令参数或明文文件。一次性凭据只用于实际 CMS 管理员登录，不重置密码、不伪造管理员身份。

为避免在争用的服务器上额外加载完整 CMS，后续执行采用本机的同版本后台配置，通过仅绑定 127.0.0.1 的固定 SSH 信任通道访问原数据库。保存仍经 Payload 登录与 `overrideAccess:false` 权限检查，新增前须核实实际迁移历史并保存公开内容快照。没有开放公网数据库端口。认证、快照和实际写入结果必须另行确认后才可将拾账记为已录入。

本机验证：录入工具当前 13 项 Python 回归、6 项生产核对回归、5 项 Node 创建/幂等回归通过，DPAPI 合成凭据加密/解密验证通过；不得把这些本地验证当作真实认证或导入成功。
