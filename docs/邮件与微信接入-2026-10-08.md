### 个人微信

个人网关现已采用隔离 Docker 部署并完成本人扫码及真实 fp 收发验收，详情见 [10 月 9 日接入记录](./DNS与微信接入-2026-10-09.md)。下面保留安装操作示例，不代表当前网关尚未部署：

```sh
openclaw plugins install '@tencent-weixin/openclaw-weixin@2.4.9'
openclaw plugins enable openclaw-weixin
openclaw channels login --channel openclaw-weixin
openclaw plugins install ./integrations/openclaw/jaxson-inbox
```

网关与 CMS 使用相同的 `STUDIO_INBOX_ALLOWED_IDENTITIES`，每项包含实际 `channelId/accountId/senderId`，不能用昵称代替 ID。默认空列表保持关闭，不能以测试假 ID 开放私人写入。

### 企业微信

优先使用官方插件的 WebSocket 智能机器人模式，需 Bot ID 和 Secret，无需先暴露公网回调。配置 `channels.wecom.dmPolicy=allowlist`、`allowFrom=[本人实际成员ID]`、`groupPolicy=disabled`。私人收件插件仍会独立检查相同三元身份，并拒绝群聊收件。

自建应用模式需要 CorpID、CorpSecret、AgentId、Token 和 EncodingAESKey；先配置网关验证参数，再在企业微信管理页保存回调地址，不能先保存一个尚未实现的地址。不要为此次收件开放插件中的邮件、文档、日历、成员管理等额外工具。

### 私人资料流向

`fp 内容` → 带身份与稳定消息 ID 的 `/api/studio/inbox` → 私人复盘/候选记忆 → CMS 审核 → 可选公开知识草稿。频道消息不会自动发布到公共 RAG。`td 内容` 仍依赖外部 Todo 服务的实际地址和密钥，当前不能承诺它已接通。

真实验收必须包括本人保存与收到回执、非本人拒绝、群聊不入库、重复消息不新增、失败不显示成功；随后验证 CMS 审核与公共 AI 引用。单元测试不能替代真实微信/公众号联调。
