# 逐屏缩放与文字重叠修复（2026-10-19）

## 问题与复现

此前缩放修复让较矮章节采用原生连续滚动，未满足放大后仍需逐屏停靠的要求。此外，全站仍存在旧响应式规则的冲突，本次不再只检查作品区的静态位置。

- 逐屏处理仅启用于宽度至少 1200px、高度至少 760px 且章节完全容纳时。960×540 下滚轮 40px 只移动 40px，逐屏行为消失。
- 960×540 顶部品牌与导航间距只剩约 1.7px；更窄时内容会挤压、折行。半透明导航背景还会透出滚过的正文。
- 首页 1024px 旧规则将三列改为纵排，后续规则仍保留中央定位的 translateX(-50%) 和受限文字列宽。960×540 肖像左边缘落在 -76.8px，首屏只有窄文字列、人物位于视口下方。
- 项目封面文字 flex 子项保留默认 min-content 宽度。320px 视口下连续英文标题右边缘约 404px，超过封面右边缘 301px，并挤压查看按钮。
- 履历的装饰年份与人物注释由宽高联合条件隐藏；放大后会重新出现。半透明经历卡允许人物手部透入文字背景。

## 行为与修复

- 桌面精细指针的逐屏处理不再绑定视口宽高。完整容纳的章节一次手势切到下一章；较长章节按可读视口高度分屏，读到内容末尾再切章，PageUp/PageDown 同样可用。
- 导航始终可直接跳章。触摸设备继续使用原生滚动；Ctrl/Meta/Alt、表单、弹窗和横向手势不被逐屏拦截。
- 计算分页末尾时忽略跟随视口的 sticky 预览，避免滚动末尾持续向前移动；不把章节尾部 padding 当作额外阅读页。
- 中等宽度首页统一为文字与人物两列，次要介绍随后排列，删除冲突的 1024px 旧规则。
- 中等宽度导航收起副标题与重复资历信息，保留完整章节链接；导航背景不透明。
- 项目封面文字允许缩小其布局占位并换行，按钮独立保留尺寸及间距。
- 履历卡背景不透明；装饰年份、人物底部注释不随放大重新出现，履历布局去掉不必要的固定最小高度。

## 可重复验证

复用现有 @playwright/test 1.58.2，无新增包。测试位于 apps/web/tests/portfolio/reflow.spec.ts，配置为 apps/web/playwright.portfolio.config.ts。

```powershell
$env:PLAYWRIGHT_CHANNEL='chrome' # 本机已有 Chrome；CI 使用安装的 Chromium
pnpm --filter @jaxson/web exec playwright test --config playwright.portfolio.config.ts
```

7 个用户行为用例分别覆盖正常动效和减少动效，共 14 项：导航间距、首页人物位置、放大后滚轮翻屏、长标题与按钮、正常整章翻页与逆向键盘翻页、可遍历至末章且可直接跳过、连续改变尺寸保持阅读章节。

前四个缺陷已分别记录修复前失败、修复后通过。CI 增加浏览器安装、回归测试及失败 trace 留存，测试 API 使用隔离的固定 fixture，不依赖线上 CMS，也不会将测试项目写入运行站点。

公网发布结果另以对应 GitHub Actions 和实际站点回归为准。
