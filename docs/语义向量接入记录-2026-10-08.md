## 数据库读账号修复

生产 `release_reader_20261007` 原搜索路径仅为 `public_read`；pgvector 类型和算子位于 `public`，导致向量查询失败并退回 CMS 文本匹配。

已执行数据库范围内的修复：

```sql
ALTER ROLE release_reader_20261007
IN DATABASE jaxson_release_20261007
SET search_path TO public_read, public;
```

重启 web 清理旧连接后，使用应用同一只读连接验收通过。私有 `owner` schema 的 USAGE、`public` schema 的 CREATE、索引表 INSERT 均为 false。没有扩大读账号对私有表或索引写入的权限。

`docker/init-schemas.sh`、`docker/migrations/002-public-index.sql` 与私有部署脚本同步补齐 pgvector 搜索路径。数据库级角色设置优先于角色全局设置；将来更换发布数据库或专用账号时仍需重新核对。
