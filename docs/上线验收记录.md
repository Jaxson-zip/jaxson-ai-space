## CMS 与知识库使用

本地默认入口：作品站 `http://localhost:3000/`，后台 `http://localhost:3001/admin`，AI `http://localhost:3001/ai`。正式环境将作品站与 CMS / AI 分别放在两个 HTTPS 域名。

在后台首页点击「新增项目经历」，或进入「作品与项目经历」新增条目。保存并设为公开后，作品站接口读取该记录。实习、教育和校园经历在「经历记录」中维护。

知识库入口是 `/admin/collections/ai-knowledge`。新增条目时填写标题、分类、事实内容及证据引用标签，勾选「是否对公开 AI 分身可见」。内容应写成可核验的事实，例如项目背景、个人职责、技术实现、结果与限制。关闭公开可见后，公开 AI 不应继续引用该条目。

当前没有「上传 PDF 后自动解析并导入知识库」入口；需先整理为文本条目。简历下载文件与知识库是两个独立来源，更新 PDF 不会自动更新 AI 知识。

CMS 的公开记录是回答事实来源。PostgreSQL `public_read.knowledge_embeddings` 是检索索引，worker 消费发布队列更新索引。默认 `EMBEDDING_MODE=local` 使用确定性文本哈希；配置独立 embedding 密钥并切换为 `semantic` 后使用语义接口。查询与 worker 仅比较相同模型标识的向量。配置 LLM 回答密钥不会自动切换索引模式；未配置 LLM 密钥时使用本地、基于检索事实的回答生成器。模拟服务测试只证明协议和故障处理，不证明真实语义模型的检索质量。
