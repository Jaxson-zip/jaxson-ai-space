## Cloudflare Access 配置

同一个 Access 应用保护 `/admin`、`/studio`、`/api/studio/memory`，允许现有 OWNER_EMAIL。
源站在 `CLOUDFLARE_ACCESS_REQUIRED=true` 时验证 RS256 签名、team issuer、应用 AUD 与 owner email。
私人 Payload API 和 collection 写入也必须持有有效 Access assertion 或签名的 CF_Authorization cookie。
公开作品与聊天接口、匿名已发布 collection 读取、授权 Inbox webhook 保持原有访问方式。

启用顺序：创建 Access 应用 → 部署已通过门禁的镜像 → 配置 team/AUD/OWNER_EMAIL 与开关 → 代理 API DNS → 本人登录验收。
只有配置存在不代表已上线；实际 CI 运行、线上健康和本人登录结果应在后续验收中记录。
